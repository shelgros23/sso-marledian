# SSO Marledian

App de SSO para la finca Marledian (DENMAR S.A.): EPP y dotación por puesto, capacitaciones, rotación de fumigación, inspecciones con escaneo de carnet y estimación de stock por talla.

- Dirección: https://shelgros23.github.io/sso-marledian/app/
- Funciona sin internet una vez instalada (Safari → Compartir → Añadir a pantalla de inicio).
- Los datos de los trabajadores se guardan solo en el celular; este repositorio contiene únicamente el programa.
